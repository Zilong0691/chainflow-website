# 08｜竞争格局与替代逻辑 — 视觉锚点提示词

## image2-primary

```
A minimalist conceptual still life: five identical-looking grey ceramic blocks (representing MLCC capacitors) arranged on a dark surface. But upon closer inspection, each has subtle differences — one is slightly smaller, one has a different metal finish on its ends, one has a tiny crack, one is perfectly pristine. The image communicates that "not all MLCCs are the same" despite looking identical at first glance. Dramatic side lighting casting long shadows. Museum plinth aesthetic — each component treated as an artifact. Dark background. No text. 3:4 vertical.
```

画面主体：五个看似相同但细节不同的陶瓷块，像博物馆展品一样排列
构图：沿水平线排列，侧光投射长阴影
风格：博物馆展品摄影——每颗器件被当作文物对待
隐喻：看起来一样，实际不同——竞争格局的核心信息
光线：戏剧性侧光
用于页面区域：页面上半部概念图
禁止元素：文字、标签

## image2-alternative

```
Close-up technical photography of two MLCC capacitors side by side — visually identical in size and shape. One is labeled with a subtle visual cue suggesting "automotive grade", the other "consumer grade". The difference between them is invisible to the naked eye — exactly the point. Clean, precise, editorial product photography. Dark background. 3:4 vertical. No text — the visual difference (or lack thereof) is the message.
```

画面主体：两颗外观完全相同的 MLCC 并排——肉眼分不出差异，暗示"车规和消费级长得一样但能力完全不同"
