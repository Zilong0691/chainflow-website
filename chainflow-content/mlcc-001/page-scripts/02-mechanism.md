章节名称：工作原理与系统作用
本页研究问题：MLCC 如何储能，又如何帮助电路稳定工作？
问题型主标题：它不只是在“存电”
专业型副标题：储能、去耦、旁路、滤波、耦合，是不同电路语境下的不同任务
目标读者：产品经理、采购、非电路专业读者
核心结论：MLCC 的价值来自在不同频段、不同电源轨和不同信号路径中提供低阻抗通路。
主要视觉：电路系统分区示意：电源轨、芯片、噪声、信号路径。
信息层级：工作原理公式 -> 五类作用分区 -> 频率/位置提示 -> 页尾判断。
辅助模块1：储能：电场储能。
辅助模块2：去耦/旁路：靠近 IC 抑制电源波动和噪声。
辅助模块3：滤波/耦合：按电路目标选择容量、ESR/ESL 和位置。
必须出现的术语：decoupling, bypass, filtering, coupling, impedance, ESR, ESL。
必须标注的数据：只标注公式 C = εrε0A/d，不标注具体参数。
事实来源：MLCC-F002。
需要生成的视觉资产：电路板局部抽象图。
需要使用SVG绘制的内容：电源轨、芯片、旁路电容、噪声路径和频率提示。
ChainFlow页尾判断：采购替代的第一步，是确认它在电路里承担的任务。
