本页研究问题：C0G、X7R、X5R 到底代表什么？
问题型主标题：三个字母，不是材料名称
专业型副标题：它们首先表达温度特性与容量稳定性，再影响应用取舍
目标读者：工程选型、采购替代、非技术读者
核心结论：C0G、X7R、X5R 是温度特性和稳定性的选型语言，不应被简化为单一化学材料。
主要视觉：一类/二类陶瓷对比矩阵与温度编码拆解。
信息层级：类别对比 -> 编码拆解 -> 应用取舍 -> 页尾判断。
辅助模块1：C0G/NP0：稳定、低容量密度。
辅助模块2：X7R：较高容量密度，宽温通用。
辅助模块3：X5R：更偏消费/空间效率，温度上限较低。
必须出现的术语：Class I, Class II, C0G/NP0, X7R, X5R, temperature characteristic。
必须标注的数据：C0G、X7R、X5R 温度/容量变化编码，最终版需标准或厂商目录复核。
事实来源：MLCC-F003, MLCC-F004, MLCC-F005, MLCC-F008。
需要生成的视觉资产：编码拆解图和对比表。
需要使用SVG绘制的内容：矩阵、标签、温度轴、稳定性/容量密度取舍箭头。
