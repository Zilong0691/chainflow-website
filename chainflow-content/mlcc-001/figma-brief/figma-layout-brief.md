# Figma 排版 Brief — ChainFlow MLCC 001

日期：2026-06-11

---

## 通用规范（十页统一）

### 画布
- 每页一个 Frame：1080 × 1440 px
- 十页放在同一 Figma 页面或各自独立 Frame

### 颜色
- 主暗底：`#111518` 至 `#1A1E24`（深石墨区间）
- 暖纸白：`#F2EDE4`（仅在需要亮底对比时使用，不作为默认背景）
- 工程蓝：`#1C4168`（标注线、连接、次要强调）
- 铜金：`#B8854A`（关键数据、公式、分隔装饰线）
- 警示红：`#C0392B`（供应链风险、瓶颈、关键警告——每页最多 2 处）
- 暖灰：`#8A8178`（辅助文字、来源、次要信息）
- 深灰：`#1A1F24`（信息区块的微提亮——不是白卡）

### 字体
- 主标题：宋体 Bold，48-76px，字距 2-6px
- 副标题：黑体 Medium，20-26px
- 正文/标注：黑体 Regular，15-19px
- 来源/页码：黑体 Regular，13-14px
- 数据数字：黑体 Bold，28-48px，优先铜金色

### 图层结构（每页必须包含，分层命名）
```
XX-PageName (Frame 1080×1440)
├── Background (底色或满版图片)
├── Brand-Header (品牌栏：系列名 + 页码 + 铜金分隔线)
├── Title-Group (主标题 + 副标题，叠在图上的可编辑文本)
├── Visual-Anchor (摄影/渲染图——可以是图片层或链接)
├── Annotation-Layer (标注线 + 标注文本——全部可编辑)
├── Data-Group (图表、数据——全部矢量或可编辑文本)
├── Footer (ChainFlow判断 + 来源标注 + 免责声明)
└── Page-Number (XX/10)
```

### 不可使用的元素
- 纯白底卡片（`#FFFFFF` + 阴影）
- 独立白底标题区
- 大面积浅米色纯色背景
- 多重投影、渐变、发光、霓虹
- 十页同一构图模板

## 分页排版要点

### 01 封面
- 构图：满版摄影 + 标题压暗部
- 背景：A-01 指尖捏 MLCC 摄影
- 标题：68-76px 宋体 Bold，暖纸白，压在画面上方暗区
- 底部：署名+覆盖范围，灰色小字

### 02 尺度冲击
- 构图：上 60% 尺度对比链条，下 40% 设备用量量级对比
- 背景：深色底 `#1A1E24`
- 尺度对比：横向三级缩放，每级圆形窗口
- 用量条形图：铜金色或工业蓝

### 03 技术结构
- 构图：左右分栏——左 55% 剖面图，右 45% 深底标注
- 背景：深色底，左栏图为 SEM 风格剖面
- 标注线从剖面引出到右栏文字
- 公式用铜金色高亮框

### 04 工作原理
- 构图：左右分栏——左 50% 温度矩阵，右 50% 降额漏斗
- 背景：深色底
- 温度矩阵用铜金色轴线和标签

### 05 材料壁垒
- 构图：上 55% 材料栈剖面，下 45% 三个壁垒信息块
- 背景：深色底 + SEM 粉体纹理
- 企业份额用铜金色标注

### 06 制造流程
- 构图：横向四列瓶颈 + 底部乘数公式
- 背景：深色底 + 工业网格纹理
- 瓶颈用红/铜金色粗线框标识

### 07 产业格局
- 构图：纵向——产业链分层 50% + 认证时间轴 30% + 洞察卡片 20%
- 背景：全页深色底 + 东亚夜光图底纹（15-25% 不透明度）
- 企业名用颜色区分国家

### 08 竞争格局
- 构图：左右分栏——左 60% 能力矩阵，右 40% 采购判断
- 背景：深色底
- 企业群色块定位在矩阵中，模糊边缘

### 09 需求风险
- 构图：上 45% 供需剪刀差，下 55% 替代三关
- 背景：深色底
- 替代三关纵向排列，底部署名

### 10 ChainFlow 判断
- 构图：五个信号卡片错落排列（3+2），底部框架连线
- 背景：深色底 + 水面摄影底纹
- 框架用五个节点+铜金箭头连线

## 可编辑性要求
- 所有中文标题、正文、标注 → Figma 文本图层
- 所有数字 → Figma 文本图层
- 所有标注线和箭头 → Figma 矢量图层
- 摄影/渲染图 → 图片图层（可替换）
- 图表和矩阵 → Figma 矢量（可编辑颜色和位置）
- 品牌标识和页码 → Figma 文本图层
- 不要将任何中文或数字 Flatten 到图片里
