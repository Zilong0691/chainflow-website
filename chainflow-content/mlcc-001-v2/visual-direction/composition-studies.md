# 三张关键页构图方案 — MLCC 001

---

## 第一张：封面页（00 — 概念封面）

### 构图方案 A1：「基石之上」

**主视觉位置**：画面中央偏下 1/3 处，一颗高质感 MLCC 渲染图居中放置。
**标题位置**：画面上 1/3 处，主标题"被低估的微小器件"居中。
**信息层级**：
1. 主标题（最大号宋体，居中）
2. MLCC 产品渲染图（视觉焦点）
3. 在主视觉上方或下方，用极细的线框勾勒出 AI 服务器/汽车/手机/工业设备的轮廓剪影——暗示"电子世界建立在这颗器件之上"
4. 副标题和署名在底部

**阅读路径**：标题 → 产品图 → 上方线框剪影 → 底部信息
**图片与矢量分工**：MLCC 渲染图（图像模型）+ 线框剪影（矢量）+ 所有文字（Figma 文本）
**手机适配**：主视觉居中突出，缩小后产品图仍然可见
**与范本对比**：从旧版"白底产品图+四周标签"升级为有隐喻的构图
**品牌一致性**：克制的隐喻表达，不煽情但有重量感

### 构图方案 A2：「剖面之门」

**主视觉位置**：画面右侧 55%，一颗 MLCC 的剖面图（半剖状态），展示内部多层结构。
**标题位置**：画面左侧 45%，主标题竖排或横排于上半部。
**信息层级**：
1. 左侧标题（主标题 + 副标题 + 署名）
2. 右侧剖面图——从外到内展示端电极→镀层→介质层→内电极
3. 底部极简信息（覆盖范围 + 不覆盖声明）

**阅读路径**：标题 → 剖面图的从外到内视线移动 → 底部
**图片与矢量分工**：MLCC 剖面渲染（图像模型生成基础材质，Figma 添加标注图层）+ 文字（Figma）
**手机适配**：左右分栏在竖屏手机端较窄，需在手机端标标题和剖面上下调换位置
**与范本对比**：封面直接展示剖面结构比纯产品图更有信息量，暗示"我们不只是看图说话"
**品牌一致性**：剖面表达预示技术深度，符合 ChainFlow 研究定位

### 构图方案 A3：「多米诺」

**主视觉位置**：画面中央，三到五颗 MLCC 等比例放大，像多米诺骨牌一样从左上到右下倾斜排列。第一颗是完整的，第二颗半剖，第三颗完全展开内部——形成"从完整到解构"的序列。
**标题位置**：画面上方偏左。
**信息层级**：
1. 主标题（左上角）
2. 多米诺序列（从左到右、从完整到解剖）
3. 底部信息

**阅读路径**：标题 → 第一颗（完整） → 第二颗（半剖） → 第三颗（全解剖） → 底部
**图片与矢量分工**：三颗 MLCC 的序列渲染（图像模型生成，带透明背景）+ 剖面标注（Figma 矢量）+ 文字
**手机适配**：倾斜排列在竖屏中自成一景，缩小后仍有"序列感"
**与范本对比**：多米诺隐喻同时传递"解构"和"风险传导"两层含义，比方案 A1 更有叙事性
**品牌一致性**："让供应链如水一般"——多米诺断裂暗示供应风险，与 ChainFlow 的供应链风险视角关联

### 推荐：方案 A3「多米诺」

**理由**：A1 太常规（谁都能做），A2 太技术（封面应留悬念），A3 兼具美学冲击力、叙事性和品牌关联。

## 第二张：技术解剖页（02 — 内部结构）

### 构图方案 C1：「建筑剖面式」- 对称剖面

**主视觉位置**：画面中央，一颗 MLCC 的正中纵向剖面——完全对称，左右端电极、中央叠层。
**标题位置**：画面上方。
**标注**：四组标注从四个方向引出——左上（介质层）、右上（内电极）、左下（端电极）、右下（镀层）。
**信息层级**：
1. 主标题 + 副标题
2. 对称剖面图（中央占 55%）
3. 四周标注
4. 底部逻辑箱（结构说明 + 公式）

**阅读路径**：标题 → 剖面中心 → 标注线引导到四周 → 底部公式
**图片与矢量分工**：100% 矢量绘制
**手机适配**：对称构图在竖屏中天然协调
**与范本对比**：旧版也是剖面，但色块堆叠缺乏材质感。新版需在矢量中增加材质暗示（渐变/纹理/线宽变化）
**品牌一致性**：技术自信的表达

### 构图方案 C2：「爆炸展开式」

**主视觉位置**：画面中央，MLCC 从中间"炸开"——左右端电极分向两侧移动，内电极逐层向上展开，介质层间隔其间。像一本打开的书的横截面。
**标题位置**：画面上方。
**标注**：标注线从每一层引出，标注材料和功能。
**信息层级**：
1. 标题组
2. 爆炸展开的主图（中央偏上，占 50%）
3. 四周标注
4. 底部等效电路和公式

**阅读路径**：标题 → 展开的层间结构 → 标注 → 底部
**图片与矢量分工**：100% 矢量绘制
**手机适配**：展开方向需控制（建议纵向展开，适配竖屏）
**与范本对比**：爆炸图比静态剖面更有"解释性"，让读者主动理解层间关系
**品牌一致性**：解构式表达有研究机构气质

### 构图方案 C3：「Zoom In 连续剖面」

**主视觉位置**：画面纵向三个放大级别——
- 顶层（最小）：整颗 MLCC 外观 + "0402 封装"
- 中层（中等）：局部放大，展示 5-6 层的电极交错 + "奇偶层交替连接"
- 底层（最大）：单层放大，展示介质层+电极+晶界结构 + "每层是一个电容单元"

三个级别从上到下排列，像显微镜的不同倍率。

**标题位置**：画面最上方。
**信息层级**：
1. 标题
2. 三级 Zoom In（从上到下排列，占 55%）
3. 各级标注
4. 底部公式

**阅读路径**：标题 → 顶层（整颗）→ 中层（层结构）→ 底层（单层细节）→ 公式
**图片与矢量分工**：顶/中层矢量，底层可加入图像模型生成的陶瓷微观纹理
**手机适配**：纵向 Zoom In 完全适配竖屏
**与范本对比**：Zoom In 序列让读者"亲自发现"，比静态剖面更有探索感
**品牌一致性**：从宏观到微观的研究视角

### 推荐：方案 C3「Zoom In 连续剖面」

**理由**：C1 太像旧版升级，C2 可能过于复杂难以在手机端辨识。C3 同时满足"一看就懂"和"细看有深度"，纵向布局天然适配竖屏。

## 第三张：产业格局页（06 — 产业链与竞争格局）

### 构图方案 E1：「分层产业链图 + 能力矩阵」双板

**主视觉位置**：上下双层——
- 上层（55%）：横向产业链分层图。从上游材料 → 中游制造 → 分销 → 下游应用。每层用不同颜色标识，标注关键企业名称和集中度。
- 下层（45%）：产品等级 × 能力维度矩阵。横轴为产品等级（消费/工业/车规/高可靠），纵轴为能力维度，不同企业群的色块分布其中。

**标题位置**：画面上方。
**信息层级**：
1. 标题组
2. 产业链分层图（上，横向阅读）
3. 能力矩阵（下，纵向阅读）
4. 底部关键数据和判断

**阅读路径**：标题 → 产业链从左到右扫视 → 矩阵从上到下解读 → 底部数据
**图片与矢量分工**：100% 矢量
**手机适配**：横向的产业链图在竖屏中需压缩宽度，建议使用分层横向条而非精细桑基图
**与范本对比**：这是十页中信息密度最高的一页，挑战在于不变成"堆砌"
**品牌一致性**：产业链 × 能力矩阵的分析框架本身是 ChainFlow 的供应链视角

### 构图方案 E2：「控制点地图」

**主视觉位置**：一张"供应链地图"——用地理隐喻但不精确对应真实地图。左上角是"日本/材料"，右上角"韩国/大规模制造"，中下部"台湾/中高端批量"，左下"中国大陆/规模追赶"，右下标注下游应用（汽车/AI/工业/消费）。
每个区域标注：控制了哪些环节、核心企业、供应风险等级（用颜色表达）。

**标题位置**：画面上方。
**信息层级**：
1. 标题
2. 供应链地图（中央，占 55%）
3. 图例和风险标签
4. 底部判断

**阅读路径**：标题 → 地图各区域 → 风险色彩 → 底部判断
**图片与矢量分工**：100% 矢量
**手机适配**：地图式布局在缩小后仍可按颜色识别风险区
**与范本对比**：用空间隐喻表达产业关系比线性流程更有"见全局"的感受
**品牌一致性**：供应链网络视角是 ChainFlow 的长期方向

### 构图方案 E3：「漏斗集中度 + 认证锁定」双视觉

**主视觉位置**：上下两个视觉——
- 上层（50%）：倒三角漏斗——最宽处是下游应用（需求分散），向上收窄到中游制造（中等集中），再到上游材料（高度集中）。漏斗中标注"控制力向上游集中"。
- 下层（40%）：认证锁定示意——一个水平的时间轴，标注"送样 → 工程验证 → 可靠性验证 → 客户批准 → 量产"。每个阶段标注典型时长，用"锁"的图标标注"一旦通过，客户不易更换"。

**标题位置**：画面上方。
**信息层级**：
1. 标题
2. 漏斗集中度图（上）
3. 认证锁定时间轴（下）
4. 底部判断

**阅读路径**：标题 → 漏斗（从上到下，越收越窄）→ 时间轴（从左到右，越走越长）→ 底部
**图片与矢量分工**：100% 矢量
**手机适配**：漏斗和时间轴都是纵向信息，适配竖屏
**与范本对比**：漏斗+认证锁两个概念清晰且互不重叠，比"堆所有信息在一张图"更利于手机端阅读
**品牌一致性**：对"控制力集中"和"认证锁定"的分析直接服务采购和供应链决策

### 推荐：方案 E3「漏斗集中度 + 认证锁定」

**理由**：E1 双板信息太多手机端难以阅读，E2 地图隐喻需要读者理解"为什么这样布局"。E3 的两个概念（集中度漏斗 + 认证锁定）直觉性强、各自一个核心信息，手机端辨识度高，且直接为下游决策提供洞察。
