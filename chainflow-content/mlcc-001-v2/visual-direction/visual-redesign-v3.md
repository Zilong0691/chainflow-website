# ChainFlow MLCC 001 — 视觉重设计 V3（对标编辑设计方法论）

日期：2026-06-11

---

## 一、核心方法论转变

### 旧思维 → 新思维

| 旧（V2 SVG） | 新（V3 编辑设计） |
|---|---|
| 在 1080×1440 画布上"画图" | 在竖版版面上"编排内容" |
| 纯色背景 + 独立标题区 + 独立图区 + 页脚 | 摄影画面铺底 + 文字压在图上 + 信息融入画面 |
| 矢量是视觉主体 | 摄影/渲染图是视觉主体，矢量只做精确标注 |
| 每页三段式 | 每页构图不同（满版、分栏、叠压、散点） |
| 色浅、轻、偏冷 | 色深、重、有重量感 |

### 新工作流

```
摄影级视觉锚点 → 版面构图设计 → 文字叠压位置 → 矢量标注补充 → Figma 合成精修
```

不是先画 SVG 再往里面加图，而是**先有图，再围绕图做版面**。

## 二、色彩系统 V3（重色体系）

### 底色系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深石墨（主暗底） | `#1A1E24` | 封面、重要分隔页的背景 |
| 深墨青（次暗底） | `#1C262A` | 技术页、产业页的可选暗背景 |
| 暖纸白（亮底） | `#F2EDE4` | 信息密集型页面的背景 |
| 档案白（次亮底） | `#EDE7DC` | 用于区分信息层级 |

### 强调色

| 角色 | 色值 | 用途 |
|---|---|---|
| 工程蓝 | `#1C4168` | 标注线、技术连接、标题强调 |
| 铜金 | `#B8854A` | 数据高亮、关键数字、标识点缀 |
| 警示红 | `#C0392B` | 风险标注（仅 1-2 处/页） |
| 暖灰 | `#8A8178` | 辅助文字、来源 |

### 功能色

| 角色 | 色值 | 用途 |
|---|---|---|
| 陶瓷介质色 | `#D4C5A0` | MLCC 结构表达 |
| 内电极色 | `#2A3540` | 镍/金属层 |
| 镀层色 | `#B0BDC5` | 锡/端电极镀层 |

### 关键规则

- **大面积永远不用纯白**（#FFFFFF）。最亮用暖纸白/档案白。
- **大面积永远不用纯黑**（#000000）。最暗用深石墨。
- 铜金只在关键数据/标注上使用，每页不超过 3 处。
- 警示红每页最多 2 处。
- 不使用任何渐变。

## 三、字体体系 V3

保持不变（宋体标题 + 黑体正文），但增加：

| 用途 | 字体 | 大小 | 字重 |
|---|---|---|---|
| 封面大标题 | 宋体 | 68-80px | Bold |
| 内页主标题 | 宋体 | 48-60px | Bold |
| 摄影画面上的标题 | 宋体 | 44-56px | Bold，颜色反白（暖纸白） |
| 副标题 | 黑体 | 22-26px | Medium |
| 正文 | 黑体 | 20-24px | Regular |
| 标注/来源 | 黑体 | 14-16px | Regular |
| 数据数字 | 黑体/DIN | 36-48px | Bold，优先铜金色 |

## 四、摄影锚点的类型学

每页需要一个摄影级视觉锚点。以下是可用的类型：

| 类型 | 示例 | 适合页面 |
|---|---|---|
| **微距产品摄影** | MLCC 在指尖、在 PCB 上的微距 | 封面、尺度页 |
| **SEM/显微成像** | MLCC 剖面、介质层、粉体颗粒 | 解剖页、材料页 |
| **工业场景** | 洁净室、流延机、烧结炉 | 工艺页 |
| **工厂/建筑外景** | 村田工厂、电子产业园 | 产业格局页 |
| **档案/历史** | 电容技术演进的老照片、专利图 | 封面、判断页 |
| **地图/航拍** | 全球电子供应链地理分布 | 产业格局页 |
| **抽象材质** | 陶瓷断面、金属断面、材料纹理 | 材料页、解剖页 |

**获取策略**（按优先级）：
1. AI 图像模型（Midjourney/Ideogram）生成——最快、可控
2. 厂商官网新闻图片——真实、可溯源
3. 授权素材库——合法、高质量
4. 公共领域/知识共享——免费、需标注

## 五、构图模式库

借用样板的多种构图，建立 ChainFlow 自己的模式：

### 模式 1：满版摄影 + 标题压暗部
- 整页铺一张摄影
- 标题叠在画面的暗部或留白处
- 底部少量信息
- **适合**：封面

### 模式 2：上下分栏——上图下文
- 上 60-65%：摄影/渲染图（可满宽）
- 下 35-40%：深色背景上放文字+数据
- **适合**：尺度冲击、材料

### 模式 3：左右分栏——左图右文
- 左 45-55%：竖图
- 右 45-55%：深色底+文字
- **适合**：参数、检查表

### 模式 4：全页信息图 + 摄影嵌入
- 流程图/结构图作为版面骨架
- 摄影小图嵌入其中点缀
- **适合**：工艺、产业链

### 模式 5：散点/地图式
- 地图或空间布局为主
- 数据点散布其上
- 文字浮动排列
- **适合**：产业格局

## 六、与旧版 V2 的切割

| V2 做法 | V3 替代 |
|---|---|
| 纯色背景 `#F4F0E8` | 摄影铺底或深色纹理背景 |
| 标题在独立区域 Y=170 | 标题压在画面上方或暗部 |
| 矢量几何块做 MLCC | AI 生成的摄影级产品图 |
| 白底半透明卡片 | 深色底上的文字直排 |
| 三段式布局 | 六种构图模式灵活选用 |
