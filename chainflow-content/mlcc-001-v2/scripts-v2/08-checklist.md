# 08 ｜ 工程与采购决策工具

## 1. 页面编号
08

## 2. 核心问题
当需要替代一颗 MLCC 时，你该怎么判断替代料是否真的能用？最容易漏掉什么？

## 3. 唯一核心结论
MLCC 替代需要电气性能、可靠性和供应链三条线同时验证——工程做技术判断，采购做供应判断，两者缺一不可。

## 4. 读者获得的新认知
"原来替代一颗小电容，需要同时验证十几项东西。原来大部分替代失败不是因为技术不行，而是因为可靠性没验证或供应跟不上。"

## 5. 主标题
替代一颗 MLCC，要过三道关

## 6. 副标题
电气参数只是第一关，可靠性验证是第二关，供应稳定性是第三关——三道关全过，替代才算成立

## 7. 主视觉对象
**三关决策流程图**：
这是一个"漏斗"或"关卡"形式的流程图（但避免简单的方框箭头）。每个关卡有若干验证项，必须依次通过。

**不是**一个静态清单，而是一个有"流向"的决策路径：
1. 参数筛选 → 通过后才进入工程验证
2. 工程验证 → 通过后才进入供应验证
3. 供应验证 → 全部通过 = 可替代

每关标注：谁负责（工程/采购/质量）、需要多久、最容易漏掉哪项。

## 8. 视觉隐喻或视觉机制
**"三道关卡"**——借鉴电路板走线或工业流程的视觉语言，但不要做成游戏化/卡通化。

三条主线（纵向或 Z 字形排列）：
- **第一关（参数关）**：容量 + 电压 + 封装 + 温度特性 + DC Bias → 基础匹配
- **第二关（验证关）**：ESR/ESL + 频率特性 + 热循环 + 板弯 + 焊接 + 老化 + 可靠性等级 → 工程确认
- **第三关（供应关）**：交期 + 渠道 + 产地 + PCN/EOL 风险 + 第二来源 + 批次追溯 + 假货风险 → 供应确认

每关通过后亮"绿灯"，三关全绿方能替代。

旁边放一个"替代决策时效参考"：从启动替代到量产验证的典型时间线（定性：参数筛选数天→工程验证数周到数月→供应确认数周到数月→客户批准数月）。

## 11. 2-4 组支撑信息
- 参数筛选（第一步）：容量、电压、封装匹配是起点——但如果介质类别不同（X7R 替代 C0G），高温性能可能完全不够
- 工程验证（第二步）：在最恶劣工作条件下（最高电压、最高温度、最老时间点）的有效容量是否满足设计余量——这是最容易跳过的步骤
- 供应验证（第三步）：替代料能不能稳定买到？会不会突然 EOL？有没有第二来源？渠道是不是授权？——这是采购日常的噩梦
- 最容易忽视的三项：DC Bias 降额、车规/可靠性认证状态、PCN/EOL 风险
- 替代时效：完整替代验证从启动到量产批准，可能需要 3-12 个月（取决于应用等级和客户流程）
