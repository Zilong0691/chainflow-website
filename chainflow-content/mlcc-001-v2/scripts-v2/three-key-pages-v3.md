# 00 封面「被低估的微小器件」

## 构图模式
**模式 1：满版摄影 + 标题压暗部**

## 版面结构

```
┌──────────────────────────────┐

│     （深空黑/深石墨背景）      │
│                              │
│    ┌────────────────────┐    │
│    │                    │    │
│    │  微距摄影：        │    │
│    │  人的指尖捏着一颗  │    │
│    │  MLCC，            │    │
│    │  景深极浅，        │    │
│    │  器件清晰，        │    │
│    │  指尖部分虚化      │    │
│    │                    │    │
│    │  画面上半部        │    │
│    │  约占 65% 面积     │    │
│    │                    │    │
│    └────────────────────┘    │
│                              │
│  被低估的微小器件  ← 标题压  │
│                     在暗区   │
│  MLCC · 多层片式陶瓷电容器   │

│  结构·参数·材料·工艺·产业链· │
│  竞争格局·替代风险           │

│  不构成投资建议 ｜ 00 / 09    │
│                              │
└──────────────────────────────┘
```

## 视觉锚点
**一颗 MLCC 被人手捏着的极端微距摄影**

画面要求：
- 手指占画面下部或一侧，虚化（浅景深）
- MLCC 器件在焦点上，极致清晰
- 可见陶瓷体和两端金属端头的材质对比
- 背景全黑或极暗
- 光源从左上方打下来，形成柔和的明暗过渡
- 不是电商白底产品图，是**有情绪、有压迫感**的微距摄影

## 文字叠压方案
- 主标题"被低估的微小器件"：宋体 72px Bold，暖纸白 `#F2EDE4`，压在画面上方暗区
- 副标题"MLCC · 多层片式陶瓷电容器"：黑体 24px，暖灰，在标题下方
- 覆盖范围：横排一行小字，半透明
- 署名 + 页码：底部，非常克制
- ChainFlow 品牌标识：页面上方极小

## 关键设计决策
- **不出现任何白框或卡片**
- **页面就是一张满版摄影 + 叠在上面的文字**
- 文字用字距和字号制造层级，不用框来制造层级
- 唯一可能加的图形元素：一条极细的铜金色横线分隔页眉和主图

## 与 V2 封面 SVG 的区别
| V2 | V3 |
|---|---|
| 几何矢量块模仿 MLCC | 摄影级微距照片做主视觉 |
| 深灰纯色背景 | 摄影画面本身做背景 |
| 标题在独立上方区域 | 标题压在画面上 |
| 多米诺序列概念 | **指尖捏器件**——更直观的尺度冲击 |

└──────────────────────────────┘
```

## 视觉锚点
**MLCC 剖面 SEM（扫描电镜）风格图像**

画面要求：
- 一颗 MLCC 的正中剖面，SEM 成像风格（灰阶、高清晰度、有真实的材料对比）
- 陶瓷介质层：较亮的灰白区域
- 镍内电极：较暗的金属灰
- 端电极：铜/镍/锡三层的真实分层可见
- 左右端头与内电极的连接关系清晰可见
- 画面整体偏暗，材质感强烈
- **不是彩色矢量图**——是黑白/灰阶的 SEM 风格，给人一种"这是真实的微观世界"的感觉

替代方案：如果 SEM 风格过于冷淡，可用**暖色调的高精度 3D 剖面渲染**，陶瓷层带暖米色，金属层带深灰——但要保持摄影级的真实感，不要出现"矢量插画感"。

## 文字叠压方案
- 左半部是剖面图
- 右半部是深色底（深石墨 `#1A1E24`）上的文字编排
- 标注从剖面图的各部件引出，连接线用工程蓝 `#1C4168`
- 底部是结构逻辑说明，暗底白字
- 等效公式用铜金色高亮

## 关键设计决策
- **不把照片放进白框**
- 剖面图紧贴左边距（或略微出血），制造"看不全"的探索感
- 标注文字在深色底上反白，不用白底卡片
- 公式框可以用铜金色边框或铜金色文字

## 与 V2 结构 SVG 的区别
| V2 | V3 |
|---|---|
| 三级 Zoom In 彩色矢量图 | 大幅 SEM/剖面摄影 + 标注 |
| 纯白纸底 | 深色右栏 + 暗底标注重叠 |
| 三层几何色块来回切换 | 一张真实剖面图 + 从图上引出的标注 |

```

## 视觉锚点
**工业摄影 + 产业地图的组合**

方案 A（推荐）：一张深色调的电子制造工业摄影做背景（如洁净室/产线/电子显微镜工作场景），**透明度降低**作为全页底纹，上面叠产业数据和图表。

方案 B：一张以东亚为中心的全球地图示意，标注粉体/制造/分销的地理分布。

## 构图结构
- **深色底**（深石墨 `#1A1E24`）铺满全页
- 工业摄影做背景底纹（15-25% 不透明度叠加）
- 标题和副标题：暖纸白，页面顶部
- 产业链分层用**横向条带**，从上游到下游自上而下排列，颜色从深（集中）到浅（分散）
- 认证时间轴用一条横向时间线，铜金色节点
- 三个洞察卡片：深底上略微提亮的区块（不透明度差异），不用白框

## 关键设计决策
- **全页深色底**，不像报告，像情报档案
- 企业名称用不同颜色区分国家/地区（日=暖铜、韩=冷灰蓝、台=暗绿灰、中=暗红铜）
- 不使用白底卡片——信息直接在深色底上呈现
- 认证时间轴用铜金色连接线，节点亮色

## 与 V2 产业格局 SVG 的区别
| V2 | V3 |
|---|---|
| 暖纸白底 + 半透白框 | 全页深石墨底 |
| 漏斗 + 时间轴分上下 | 产业地图 + 漏斗 + 时间轴融为一体 |
| 文字在浅色背景上 | 文字在深色背景上反白 |
| 矢量纯排版 | 工业摄影底纹 + 数据叠压 |

# 跨三页的统一性

| 元素 | 00 封面 | 02 解剖 | 06 格局 |
|---|---|---|---|
| 背景 | 摄影满版（指尖+MLCC） | 左图（SEM剖面）+右深底 | 全页深底+工业摄影纹理 |
| 标题位置 | 压在画面暗部 | 右栏顶部 | 页面顶部 |
| 主色调 | 深黑+暖白字 | 灰阶图+深石墨右栏 | 深石墨+铜金点缀 |
| 标注方式 | 无 | 从图上引出线 | 直接标注 |
| 卡片 | 不用 | 不用 | 不用（深底提亮区块替代） |

三张页面的统一来自：**字体体系、颜色体系（深石墨/工程蓝/铜金/暖纸白）、标注线样式、无白框原则**。
不是来自相同的构图模板。
