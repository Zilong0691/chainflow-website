# 04 ｜ 参数与选型

## 1. 页面编号
04

## 2. 核心问题
C0G、X7R、X5R 这些代号是什么意思？为什么标称 10μF 的电容，焊到板上后实际可能只剩 3μF？

## 3. 唯一核心结论
温度特性编码告诉你在不同温度下容量怎么变，DC Bias 告诉你加了电压后容量怎么降——标称容量不是答案，工作条件下的有效容量才是。

## 4. 读者获得的新认知
"原来 X7R 不是材料名字，而是一套温度-容量变化规则。原来同一个料号在不同电压和温度下，有效容量差别可以这么大。"——从看标签到看曲线。

## 5. 主标题
标称 10μF，上板可能只剩 3μF

## 6. 副标题
温度特性（C0G/X7R/X5R）说的是热稳定性，DC Bias 说的是电压下降额——两者共同决定有效容量

## 7. 主视觉对象
双面板构图：
- **左侧**：温度特性矩阵——C0G / X7R / X5R 的对比，用温度轴 + 容量变化带
- **右侧**：DC Bias 降额链条——标称容量（100%）→ 加 DC 偏压→ 工作温度→ 老化效应→ 有效容量（?%），每一步标注"损失多少"（以一条真实型号的公开曲线为示意基础）

## 8. 视觉隐喻或视觉机制
**"漏斗/降额链条"隐喻**：标称容量是漏斗顶部的 100%，经过 DC Bias、温度、老化三个滤网后，底部流出的有效容量可能是 20-70%。
每个滤网标注：什么因素、影响幅度、用户能做什么（选型建议）。

**左半板**：温度特性编码拆解
- 用 EIA 编码规则展开：第一个字母（低温）、第二个数字（高温）、第三个字母（容量变化）
- 将 C0G、X7R、X5R、Y5V 四个典型编码展开对比
- 横轴为温度范围，纵轴为容量变化百分比，每种画一条带（容差范围）

## 11. 2-4 组支撑信息
- Class I（C0G/NP0）：温度稳定性极高（±30ppm/°C），容量密度低，适合精密电路
- Class II（X7R）：宽温范围（-55~+125°C），容量变化 ±15%，通用型主力
- Class II（X5R）：温度上限较低（+85°C），适合消费电子但高温场景慎用
- Class II（Y5V）：温度稳定性差（+22%/-82%），低端消费电子
- DC Bias 降额幅度依赖型号、尺寸、额定电压——小封装高容量料号的降额最严重
- 老化效应：Class II 陶瓷电容容量随时间缓慢下降（每十倍时间约降 2-10%，依材料体系而异）

## 12. 必须出现的数据
- C0G、X7R、X5R、Y5V 的温度/容量变化编码（需 EIA-198 复核）
- 一条真实型号的 DC Bias 曲线示意（需标注型号和来源）
- 老化率量级（每 decade hour 的百分比范围）

## 13. 数据来源
MLCC-F003, F004, F005（分类编码）、MLCC-F006, F007（DC Bias 和老化）、MLCC-F016（DC Bias 降额幅度范围）、待补 EIA-198 标准

## 14. 技术标注文本
- 编码规则展开：EIA-198 标准

- 老化率标注：每十倍时间（decade hour）约降 X%
- 所有标注需说明适用条件
