# 官网地球恢复与监测

地球的通用渲染代码、NASA 地表贴图与世界边界随官网同域发布，不再从临时演示隧道读取。地球显示与三流、风险列表相互独立。

- 浏览器确认实际绘制首帧后才隐藏静态地球。资源加载失败、绘制节点丢失或 WebGL 上下文中断时，保留静态球并自动重建。
- 重试间隔为 1、2、4、8、16、30 秒，之后保持 30 秒。成功后重置。卸载或取消后的旧回调不再重建。
- 网络等待最多 25 秒；挂载后的首帧只计算页面可见且球体在屏幕内的等待时间。减少动态效果、滚动离开和隐藏标签页不应触发误重试。
- 每次构建核对锁定资源 SHA-256 和交互契约，失败即中止构建。

## 资源来源

通用渲染器的锁定输入在 `lib/globe/globe-renderer.js`，保留 Three.js 许可声明。地理输入在 `public/world-land.geojson` 与 `public/earth-surface.jpg`。版本清单由 `lib/globe/asset-contract.mjs` 定义，发布目录由 `scripts/build-globe-assets.mjs` 生成。资源中没有企业供应商、价格、联系人或订单记录。

更新通用渲染器时，必须同步资源摘要并跑浏览器故障检查，不应只更改摘要来绕过校验。

## 检查方式

- `npm test`：资源内容、恢复退避、已取消回调与健康判定。
- `npm run build`：从 Git 中的输入重新生成资源，并验证生产构建。
- `npm run monitor:globe -- https://www.chainflowlab.com`：检查线上清单、三份资源内容和静态兜底。返回成功 HTTP 状态并不足以通过。
- `scripts/probe-globe-browser.js`：通过 Playwright CLI 检查实际首帧、NASA 贴图和 15 秒后的稳定性。
- `scripts/check-globe-recovery.js`：注入清单、渲染器、地理边界失败，验证解除后自动恢复；同时检查上下文中断、节点丢失、移动端、英文、减少动态效果与初始隐藏状态。

## 后台运行

`官网地球健康检查` 工作流在默认分支启用后，每半小时检查线上资源和实际浏览器画面，保存日志与截图；可手动执行。GitHub 的定时触发可能延迟，不是毫秒级监控。GitHub 默认会在仓库 60 天无活动时停用公开仓库的定时工作流，需要恢复。

`地球发布验证` 在推送到 main 或打开面向 main 的 PR 后运行构建与故障检查。

自动恢复发生在访问者的浏览器中；后台检查负责发现站点级异常。检查失败不会盲目回滚或重新发布旧设计，须根据错误定位原因，验证修复再发布。风险资讯是否为最新内容属于资讯来源的独立检查，不能仅由地球画面通过而推断。
