# NetworkFlow 能力说明

## 当前状态

- 阶段：Prototype（可交互 Demo）
- Demo 位置：`public/demos/networkflow/index.html`
- 网站入口：`/tools/networkflow`
- 数据：硬编码 5 个候选仓点、386 个需求城市，预计算分配方案

## 当前能力

基于需求城市和候选仓点：
- 比较不同仓网布局方案
- 推荐仓点数量和位置
- 输出需求分配明细
- 成本拆分（固定成本 + 运输成本）
- 覆盖率计算
- 交互式仓网地图
- 多方案成本曲线对比

## 当前限制

- 数据硬编码，不接受外部上传
- 无输入校验
- 无结构化 JSON 输出
- 移动端参数面板无法滚动
- 暂未覆盖库存策略
- 暂未覆盖税务和真实运营约束

## 长期能力定位

**供应链网络设计与资源配置模块**

在 ChainFlow 三层中属于第一层（效率层）和第二层（决策层）的桥梁。
当前以效率工具形式交付，但随着约束条件增加和多目标优化，
自然演进为决策辅助工具。

未来：
- DemandFlow 预测区域需求 → NetworkFlow 重新评估仓网
- SupplierScore 评估供应商位置 → NetworkFlow 纳入供应端约束
- 与 RouteFlow 组合形成"仓网→配送"完整链路

## 标准化改造路线

1. 保持现有 Demo 不动
2. 撰写 `module.json`（已完成模板）
3. 整理示例输入 JSON（需求城市 + 候选仓 + 成本参数）
4. 整理示例输出 JSON（推荐仓点 + 分配 + 成本 + 覆盖率）
5. 增加输入校验
6. Next.js 重写前端
7. 增加敏感性分析（参数变化对方案的影响）
