# 官网视觉重构

## 任务合同
- 目标：学习指定参考站的文字入场、动效和Demo展示，重做对外官网。
- 范围：官网首页、响应式导航、可操作人工齐料片段、真实产品截图及既有三维供应地球；固定/demo与原工具入口保留。
- 禁止改动：不改内部工作台业务，不复制公司点位、联系人、BOM或凭据；不发布原官网目录未验开发；不复制参考站品牌、文案、账号和服务。
- 验收：桌面/平板/手机排版、英文切换、三维拖动、Demo数量重算与步骤切换、键盘和减少动效模式、原工具与/demo跳转；构建及既有回归通过，发布后实际回读。

## 设计依据
参考https://interviewasssistant.com/zh，REA独立浏览器桌面与手机采集，证据保存在库外。吸收大字层级、文字递进入场、可变化的产品片段；不采用其业务承诺及数值。
Taste方向：product-performs，seed 2074123443。用户指定参考优先，配色由随机森林绿调整为深蓝黑/白/功能蓝，三维地球采用原产品材质；不采用随机摄影。
核心想法：将ChainFlow从BOM到齐料的核对过程变成访客可以直接调整套数与查看修订的演示。
产品片段只使用人工案例，原实际截图不含公司信息；不把模拟动作称为实时模型或真实邮件。

## 地球复用
通用Three.js引擎来自同一ChainFlow已验版本，仅调整导入并移除无关高德导出；地点独立构造，保留拖动、自转、球外连线、点位呼吸及离屏暂停。引擎来源记录在lib/globe/PROVENANCE.json。

## 动效与素材
- 标题按两行遮罩入场，随后出现正文和操作；章节只进入一次，不劫持滚动。
- 产品片段约6.8秒切换，可暂停、重放；手动调整立即停止自动切换。文字逐步出现，减少动效时直接展示全文。
- 地球沿用原相机、材质、飞线和离屏暂停。官网关闭滚轮缩放，保留页面正常滚动、拖动和复位；城市为独立构造示意，原企业业务处理仅保留坐标校验。
- 四张模块图片由完整外部人工版实际截取，不是参考站图片或公司截图。地球底图为原产品NASA Blue Marble；无额外素材授权和外部字体请求。
- 官网不使用视频，原因是三维引擎与可操作产品片段已经展示运行状态；不以无关视频装饰。产品片段内沿用可读的多层界面字号，营销正文保持16px。
