📐 两阶段选址数学模型

◆ 集合与参数

I = {1,2,…,m} — 需求城市集合 (m=165)

J = {1,2,…,n} — 候选仓库集合 (n最多可扩展至20)

dij — 仓库 j 到需求点 i 的距离 (km)

wi — 需求点 i 的年需求量 (吨)

fj — 仓库 j 的年固定成本 (元/年)

c — 单位运输费率 (元/吨·公里)

Qj — 仓库 j 的最大容量 (吨/年)

◆ 决策变量

yj ∈ {0,1} — 是否在候选点 j 建立仓库

xij ∈ {0,1} — 需求点 i 是否分配给仓库 j

◆ 目标函数

Min Z = Σj∈J fj·yj + c·Σi∈IΣj∈J dij·wi·xij
   + M·Σj∈J max( 0, Σi∈I wi·xij − Qj·yj )

第一项：仓库固定成本；第二项：运输可变成本；第三项：容量惩罚成本（软约束，M=2×max(dij)）

⚠ 惩罚项理论依据：标准FCFLP模型对容量约束 Σwixij ≤ Qjyj 要求严格满足。当候选仓库有限且需求量较大时，严格约束可能导致无可行解。惩罚项将硬约束松弛为软约束——超出部分按"外包至2倍最远距离"的成本计罚，等价于将超量需求临时外包给备用仓库的代价。这是运筹学中常用的"Big-M"软约束方法，在物流实践中对应应急仓储/临时租仓的成本。若惩罚成本>0，即向使用者提示当前容量不足，需考虑增加仓库或提高容量系数。

◆ 约束条件

① 需求覆盖约束：每个需求城市必须分配给恰好一个仓库

Σj∈J xij = 1, ∀i∈I

② 开放约束：只能分配给已开放的仓库

xij ≤ yj, ∀i∈I, j∈J

③ 容量约束：分配给仓库的总需求不超过其容量

Σi∈I wi·xij ≤ Qj·yj, ∀j∈J

⚠ 容量约束说明：标准MILP模型对容量约束严格满足。前端交互求解器采用贪心+2-opt启发式算法，当候选仓库有限时，允许方案的容量超出通过惩罚项体现——即「超载运行」表示在当前容量系数下，某仓库承载了超额需求。这不是bug，而是向使用者反馈：当前容量不足，需考虑提高容量系数或增加仓库。若惩罚成本=0，说明方案在容量约束下完全可行。

④ 选取数量约束：（可选）指定仓库数量

Σj∈J yj = p (或 ≥ pmin)

⑤ 决策变量取值

yj ∈ {0,1}, xij ∈ {0,1}

◆ 求解方法

模型类型：混合整数线性规划 (MILP) — 固定费用设施选址问题 (FCFLP)

求解引擎：OR-Tools SCIP/CBC (开源MIP求解器)

前端交互求解：贪心构造 + 2-opt 局部搜索（支持最多20个候选城市）

・贪心构造：依次选择最能降低总成本的候选仓库

・局部搜索：随机替换已选仓库与未选仓库，若改善则接受

◆ 参数假设说明

原数据缺失运输单价、仓库固定成本和容量。求解时按行业常识假设：固定成本=50万元/年·仓库，运输费率=0.5元/吨·公里，每单平均重量=10吨，容量系数=1.5×当前量。页面提供交互式滑块调整参数观察影响。

新增候选城市的容量按「平均吞吐量基准」估算，即所有原始供应城市平均吞吐量 × 容量系数。
