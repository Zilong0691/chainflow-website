# DemandFlow — 需求预测与补货决策助手

## 当前状态：Idea（设计阶段，尚未开发）

## 要解决的业务问题

小企业和供应链团队当前做需求判断时：
- 依赖经验，缺乏数据支撑
- 促销和季节性波动难以量化
- 缺货和积压同时存在
- 安全库存拍脑袋
- 补多少、什么时候补，缺少系统性建议

## 完整决策链设计

```
历史需求 → 数据质量检查 → 需求预测 → 当前库存快照 →
缺货与积压风险识别 → 安全库存建议 → 补货数量与时间 →
多情景比较（乐观/基准/悲观）→ 人工确认 → 结果反馈与校准
```

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 历史需求 | 是 | SKU × 日期 × 数量，含促销标注 |
| 当前库存 | 是 | SKU × 在库量 × 预留量 × 安全库存 |
| 预测配置 | 否 | 预测周期、粒度、置信度 |
| 业务事件 | 否 | 促销日历、节假日、新品上市 |
| 供应商信息 | 否 | 交期、MOQ，用于联动补货建议 |

## 输出

- 预测需求（含置信区间）
- 缺货风险清单（哪些 SKU 几号可能断货）
- 积压风险清单（哪些 SKU 库存过高）
- 安全库存建议
- 补货建议（补什么、补多少、什么时候下单）
- 多情景对比表（乐观/基准/悲观）

## 可复用的公共对象

- Product/SKU
- Demand
- Inventory
- Order
- Supplier（补货联动）
- RiskEvent（缺货/积压风险）
- Recommendation

## 可调用的模块

- StockCheck（库存核对与缺口验证）
- SupplierScore（供应商评估，补货决策参考）

## 可被调用的场景

- RouteFlow：预测到某区域需求增加 → 提前规划运力
- NetworkFlow：预测到结构性需求变化 → 重新评估仓网

## 当前边界

- V0.1 不接入实时销售数据
- 不替代企业 ERP 中的 MRP 模块
- 预测结果仅作为辅助判断，不自动触发采购
- 暂不支持多级 BOM 的衍生需求计算

## 开发前置条件

1. RouteFlow 和 NetworkFlow 标准化改造完成
2. 公共请求/结果格式稳定运行
3. 至少 2-3 个真实或模拟数据集用于验证

## 数据安全

- 默认使用脱敏或模拟数据
- 不主动收集敏感信息
- 预测结果不作为唯一决策依据

## 长期定位

预测与决策智能模块。是 ChainFlow 从效率层（Efficiency）
走向决策层（Decision）的第一个桥梁模块，也是第二层
"帮你做判断"的核心落地。
