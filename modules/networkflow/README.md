# NetworkFlow — 仓网选址评估助手

## 当前状态：Prototype（完整 Demo + Next.js 外壳）

| 版本 | 路径 | 定位 |
|------|------|------|
| 旧 HTML Demo | `public/demos/networkflow/index.html` | **完整功能版**（参数调整、重新求解、成本拆分、城市分配表、数学模型） |
| Next.js 页面 | `app/tools/networkflow/page.tsx` | iframe 嵌入完整 Demo + 顶栏统计 + JSON 导出 |

Next.js 页面通过 iframe 保留旧 Demo 全部交互，不做功能替换。

## 解决什么问题

基于需求城市、候选仓点和成本参数，快速比较不同仓网布局方案。

## 适合谁

区域仓规划、出海仓评估、经销网络优化团队。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 需求城市列表 | 是 | 含编号、名称、经纬度、预估订单量 |
| 候选仓列表 | 是 | 含编号、名称、经纬度、固定成本、容量、服务半径 |
| 运输参数 | 否 | 每单每公里成本、最大仓数、最低覆盖率 |

完整定义见 `input.schema.json`。

## 输出

- 推荐仓点列表
- 需求城市分配明细（哪个需求城市分配到哪个仓）
- 成本拆分（固定成本 + 运输成本）
- 覆盖率计算
- 备选方案（成本优先 / 服务优先 / 均衡方案）
- 交互式仓网地图（HTML）

完整定义见 `output.schema.json`。

## 当前限制

- 数据硬编码，不接受外部上传
- 无输入校验
- 成本为估算值
- 距离为直线估算
- 移动端参数面板无法滚动

## 适配说明

同 RouteFlow。本模块目录提供标准接口的"描述"层，
不修改原有 Demo HTML。

## 数据安全

Demo 使用模拟数据。不承载真实业务文件。

## 运行校验

```bash
node src/validate.js examples/valid-input.json
```

## 长期定位

供应链网络设计与资源配置模块。可作为 DemandFlow 和
SupplierScore 的空间决策层，与 RouteFlow 组合形成
"仓网→配送"完整链路。
